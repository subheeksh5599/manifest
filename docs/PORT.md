# The landing page: where it came from and what was changed

`app/app/page.tsx` is a port of a supplied single-file design export. The export's
own markup is the design; the words are ours.

## What was kept, exactly

Section order, the 1240px container and its gutters, the 12-column grid, every
Tailwind class string, the type ladder, the palette (`#1a1a1a` obsidian,
`#edeff2` cloud, `#dedfe1` hairline, `#e2e7fc` glacier, `#2962ff` cobalt), the
2px corners, the sticky header, all eleven sections, and every decorative SVG
path character for character — including the six gradient layers of the hero
panel, which are the export's own artwork and are copied verbatim.

Nine sections, counted in the render, matching the export one for one: hero,
social-proof strip, data layer, the desk, the tape, evidence, the paste-a-mint
band, the pillars, the three-product comparison.

## What was changed

Only strings, plus the destinations the strings point at.

- Copy: every heading, paragraph, list item, badge, metric, card title, footer
  column and the wordmark. No sentence of the export's copy survives.
- Metric cells carry this project's own counts (423 tests, 31 receipt checks,
  6 named refusals) rather than the export's, and no traction, partner or
  customer claim is made anywhere.
- Calls to action: the export's twelve `href="#"` anchors are wired, in document
  order, to `/exit`, `/verify`, `/evidence`, `/tape` and `/`. The list is
  asserted in the port script, so the count cannot drift silently.
- Two anchors the export pointed at nothing — the social icons for accounts this
  project does not have — are removed rather than pointed somewhere false. The
  two that exist (repository, X) are real links.
- The newsletter band, which in the export collects an email it has nowhere to
  send, is now a real read: paste a mint and it takes you to that mint's terms
  (`app/components/quick-read.tsx`).
- The status column states facts in words. No address, chain id, faucet link,
  balance or network name appears on this page: the landing carries design facts,
  and the numbers that come off a network live on the desk one route over.
- `--color-obsidian`, `--color-hairline`, `--color-glacier`, `--color-cobalt` and
  `--radius-sharp` were added to the `@theme` block so the export's own token
  names resolve, and the whole page shares one stylesheet with the desk.

## Regenerating it

`app/app/page.tsx` is generated by a script that applies an explicit, asserted
substitution table to the export and converts it to JSX. Every anchor asserts
that it matched; a miss raises instead of shipping the previous product's copy.
The generated file is committed, and the script is deliberately not: the point of
the copy table is that it is reviewable as a diff against the export, not that it
runs in CI.
